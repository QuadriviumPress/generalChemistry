# Diagram replacements

Updated 2026-10-30. This covers the **40 diagram locations** in the [initial missing-figure audit](figure-replacement-audit.md): the 38 SVG routes and the 2 photo/diagram hybrids. The [machine-readable ledger](../figure-replacements.json) remains the source of truth.

**All 40 are installed** as original SVG diagrams in `images/replacements/fig-*.svg`. The two hybrids (4.21 copper and silver nitrate, 6.9 hydrogen emission) use the audit's full-schematic fallback in place of a photograph, and their captions no longer refer to photographs. Together with the photographs, 61 of 65 locations are installed. The four pending locations are photographs; see [photograph replacement progress](photograph-replacements.md).

## How the diagrams were made

Each diagram was drawn fresh from its source caption, the surrounding text, and checked scientific data. None traces or adapts the lost artwork or a third-party SVG. Every image slot still holds exactly one image, so rendered-coverage counts are unchanged. Each SVG has a white background, so it stays legible in dark mode, and carries its own `<title>` and `<desc>`. The Markdown alternative text repeats the description.

Captions were kept where they already matched the drawing. Where they did not, the change is recorded in the entry's `editorial_change` and in [SOURCES.md](../SOURCES.md). Colors of solutions and precipitates are schematic, as several captions now say.

## Ledger fields for original diagrams

An original diagram asset has `"origin": "original"` and records `title`, `creator`, `license`, `license_url`, `created`, `basis` (the facts or data it was drawn from), `sha256`, and `path`. It has no download URLs or retrieval date. `scripts/figure_replacements.py` checks these fields, and the regression tests cover both asset kinds.

## Editing a diagram

The diagrams are generated by `scripts/diagrams/`, a small standard-library Python drawing kit (`lib.py`) with one function per figure (`figs_a.py` through `figs_c.py`). To change a diagram:

1. Edit its function, then run `python3 scripts/diagrams/render.py FR032` (or no argument for all). It rewrites the SVG and prints its new SHA-256.
2. Update that `sha256` in `figure-replacements.json`. If the caption or alternative text changes, update the entry's `replacement.markdown` and the chapter text together; the verifier requires them to match exactly. The alternative text repeats the SVG's `<desc>`.
3. Run `python3 -m unittest discover -s tests`, `npm run verify`, and `npm run check`. A regression test runs `render.py --check`, so a hand edit to an SVG that is not reflected in the generator fails.

Chemistry markup in labels: `_2` or `_{12}` gives a subscript, `^+` or `^{2−}` a superscript.
